# Cardevia PWA Deployment Guide

This comprehensive guide will help you deploy the Cardevia Flutter mobile app as a Progressive Web App (PWA) that works seamlessly on both Android and iOS devices.

## 🚀 Quick Start

```bash
# Make the deployment script executable
chmod +x deploy-pwa.sh

# Build and prepare PWA
./deploy-pwa.sh

# Deploy to Firebase (optional)
./deploy-pwa.sh firebase

# Deploy to Vercel (optional)
./deploy-pwa.sh vercel
```

## 📋 Prerequisites

1. **Flutter SDK** (latest stable version)
2. **Git** for version control
3. **Node.js and npm** for deployment tools
4. **Hosting platform account** (Firebase, Vercel, Netlify, etc.)

### Install Required Tools

```bash
# Install Firebase CLI (for Firebase deployment)
npm install -g firebase-tools

# Install Vercel CLI (for Vercel deployment)
npm install -g vercel

# Install Netlify CLI (for Netlify deployment)
npm install -g netlify-cli

# Install Lighthouse CLI (for PWA testing)
npm install -g lighthouse
```

## 🛠️ Manual Build Process

If you prefer to build manually instead of using the deployment script:

```bash
# 1. Clean previous builds
flutter clean

# 2. Get dependencies
flutter pub get

# 3. Build for web (choose one option)

# Standard PWA build with offline-first caching
flutter build web --release --pwa-strategy offline-first

# Advanced: WebAssembly build for better performance
flutter build web --release --wasm --pwa-strategy offline-first

# 4. Your PWA files will be in the build/web directory
```

## 🌐 Deployment Options

### Option 1: Firebase Hosting (Recommended)

Firebase Hosting provides excellent PWA support with automatic HTTPS and global CDN.

#### Setup

```bash
# 1. Login to Firebase
firebase login

# 2. Initialize Firebase project
firebase init hosting

# Follow prompts:
# - Select existing project or create new one
# - Set public directory to: build/web
# - Configure as single-page app: Yes
# - Overwrite index.html: No

# 3. Deploy
firebase deploy
```

#### Configuration

The included `firebase.json` file is pre-configured with:
- Proper routing for Flutter's single-page app
- Cache headers for optimal performance
- Service worker cache invalidation

### Option 2: Vercel

Vercel offers seamless deployment with automatic HTTPS.

#### Setup

```bash
# 1. Login to Vercel
vercel login

# 2. Deploy (from project root)
vercel --prod

# Or deploy from build directory
cd build/web
vercel --prod
```

#### Configuration

The included `vercel.json` file provides:
- Automatic Flutter build commands
- Proper routing configuration
- Optimized cache headers

### Option 3: Netlify

Netlify supports drag-and-drop deployment or CLI deployment.

#### Manual Deployment

1. Build your app: `flutter build web`
2. Go to [Netlify](https://netlify.com)
3. Drag and drop the `build/web` folder

#### CLI Deployment

```bash
# 1. Login to Netlify
netlify login

# 2. Deploy
netlify deploy --prod --dir=build/web
```

### Option 4: Other Static Hosting

Any static hosting service works:
- **GitHub Pages**: Upload to `gh-pages` branch
- **AWS S3 + CloudFront**: Upload to S3 bucket
- **DigitalOcean Spaces**: Static website hosting
- **Traditional web hosting**: Upload via FTP/SFTP

**Requirements:**
- HTTPS enabled (mandatory for PWA)
- Proper MIME types for all file extensions
- Single-page app routing support

## 🧪 Testing Your PWA

### 1. Local Testing

```bash
# Test locally during development
flutter run -d chrome

# Or serve the built version
cd build/web
python -m http.server 8000
# Visit http://localhost:8000
```

### 2. Lighthouse Audit

```bash
# Run comprehensive PWA audit
lighthouse https://bluelight.fluxpointstudios.com --view

# Or use Chrome DevTools
# 1. Open your deployed PWA in Chrome
# 2. Press F12 for DevTools
# 3. Go to Lighthouse tab
# 4. Select "Progressive Web App" category
# 5. Click "Generate report"
```

### 3. Device Testing

#### Android Testing
1. Visit your PWA URL in Chrome
2. Look for install prompt or "Install App" in menu
3. Install and launch from home screen
4. Test offline: Turn off network, launch app
5. Verify splash screen and theming

#### iOS Testing
1. Visit your PWA URL in Safari
2. Tap Share button → "Add to Home Screen"
3. Confirm app name and icon
4. Launch from home screen
5. Verify standalone mode (no Safari UI)

### 4. PWA Validation Checklist

- [ ] **Manifest loads correctly** (no 404 errors)
- [ ] **Service worker registers** (check DevTools → Application → Service Workers)
- [ ] **Icons display properly** (home screen and splash)
- [ ] **Offline functionality works** (airplane mode test)
- [ ] **Install prompt appears** (Android Chrome)
- [ ] **Standalone mode works** (no browser UI when launched)
- [ ] **Theme colors apply** (status bar, splash screen)
- [ ] **Performance is good** (Lighthouse score > 90)

## 🔧 Troubleshooting

### Common Issues

#### Service Worker Not Registering
```javascript
// Check browser console for errors
// Common causes:
// - Not served over HTTPS
// - JavaScript errors blocking registration
// - Incorrect service worker path
```

#### PWA Not Installable
- Check manifest.json for syntax errors
- Ensure all icon files exist
- Verify HTTPS deployment
- Test with Lighthouse audit

#### Icons Not Appearing
- Verify icon file paths in manifest.json
- Check file sizes match declared sizes
- Ensure icons are accessible (no 404s)
- Test different formats (PNG recommended)

#### Offline Mode Not Working
- Check service worker is active
- Verify resources are being cached
- Test after full page reload
- Check browser storage settings

### Debug Commands

```bash
# Check PWA manifest
curl -I https://your-domain.com/manifest.json

# Test service worker
curl -I https://your-domain.com/flutter_service_worker.js

# Validate HTML
curl https://your-domain.com | head -20
```

## 🚀 Performance Optimization

### Build Optimizations

```bash
# Enable tree shaking (removes unused code)
flutter build web --release --tree-shake-icons

# Optimize for web
flutter build web --release --web-renderer html --dart-define=FLUTTER_WEB_USE_SKIA=false

# Profile bundle size
flutter build web --release --analyze-size
```

### Hosting Optimizations

1. **Enable Compression** (gzip/brotli)
2. **Set Cache Headers** (included in config files)
3. **Use CDN** (Firebase/Vercel provide this)
4. **Optimize Images** (WebP format)
5. **Minimize JavaScript** (automatic in release builds)
