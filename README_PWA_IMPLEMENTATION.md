## 🚀 Quick Start Guide

### Option 1: Automated Deployment (Recommended)

#### Windows Users:
```cmd
# Build and deploy
deploy-pwa.bat

# Or auto-deploy to Firebase
deploy-pwa.bat firebase

# Or auto-deploy to Vercel
deploy-pwa.bat vercel
```

#### Linux/Mac Users:
```bash
# Build and deploy
./deploy-pwa.sh

# Or auto-deploy to Firebase
./deploy-pwa.sh firebase

# Or auto-deploy to Vercel
./deploy-pwa.sh vercel
```

### Option 2: Manual Build

```bash
# 1. Clean and prepare
flutter clean
flutter pub get

# 2. Build for web
flutter build web --release --web-renderer html

# 3. Deploy build/web directory to your hosting platform
```

### Option 3: NPM Scripts

```bash
# Install deployment tools
npm install

# Build PWA
npm run build

# Deploy to various platforms
npm run deploy:firebase
npm run deploy:vercel
npm run deploy:netlify
```

## 🧪 Testing Your PWA

### Automated Testing
```bash
# Windows
test-pwa.bat

# Linux/Mac
./test-pwa.sh
```

### Manual Testing Steps

1. **Deploy to HTTPS hosting** (Firebase, Vercel, Netlify)
2. **Test on Android Chrome**:
   - Visit your PWA URL
   - Look for "Install App" prompt
   - Install and launch from home screen
   - Test offline functionality

3. **Test on iOS Safari**:
   - Visit your PWA URL
   - Tap Share → "Add to Home Screen"
   - Launch from home screen (should be full-screen)

4. **Run Lighthouse Audit**:
   ```bash
   lighthouse https://your-domain.com --view
   ```

## 🌐 Deployment Platforms

### Firebase Hosting (Recommended)
```bash
# Setup
firebase login
firebase init hosting  # Select build/web as public directory
firebase deploy
```

### Vercel
```bash
# Setup
vercel login
vercel --prod
```

### Netlify
- Drag and drop `build/web` folder to Netlify dashboard
- Or use CLI: `netlify deploy --prod --dir=build/web`

## 🆘 Troubleshooting

### Common Issues
- **PWA not installable**: Check manifest.json syntax and HTTPS
- **Icons not showing**: Verify icon file paths and sizes
- **Offline not working**: Check service worker registration
- **iOS issues**: Ensure Apple Touch Icons are properly linked

### Debug Tools
- **Chrome DevTools**: Application tab → Manifest, Service Workers
- **Lighthouse**: PWA audit and recommendations
- **Browser Console**: Check for errors during registration
